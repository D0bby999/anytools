title: Calculadora de porcentagem — Perguntas frequentes
---

## Quais são os três modos?

**X% de Y** multiplica: `(x / 100) × y`. **X é quantos por cento de Y** divide: `(x / y) × 100`. **Mudança percentual** compara dois valores: `((para − de) / de) × 100`. A maioria das perguntas sobre porcentagem é uma destas três com palavras diferentes.

## Como escolho a correta?

Pelo que está faltando. Se você sabe a porcentagem e quer um valor, use a primeira. Se você tem dois valores e quer a porcentagem, use a segunda. Se você tem um antes e um depois, use a terceira.

## Por que um aumento de 50% seguido por uma queda de 50% não volta para onde comecei?

Porque cada porcentagem se aplica a uma base diferente. Pegue 100, adicione 50% para chegar a 150, depois remova 50% de 150 — isso é 75, não 100. A mudança percentual é sempre relativa ao valor pelo qual você começou, é por isso que a direção da comparação importa.

## Qual é a diferença entre por cento e pontos percentuais?

Uma taxa movida de 4% para 6% subiu dois *pontos* percentuais, mas 50 *por cento*. Ambas as afirmações são verdadeiras e descrevem o mesmo movimento. Relatórios financeiros e políticos rotineiramente desfocam isso, geralmente para qualquer número que pareça maior.

## Por que a mudança percentual retorna zero quando o valor inicial é zero?

Porque a mudança seria uma divisão por zero — passar de nada para algo não tem um percentual finito. Em vez de emitir uma infinidade, a ferramenta retorna zero. Se seu valor "de" for genuinamente zero, mudança percentual não é a medida certa; declare a mudança absoluta em vez disso.

## Posso usá-la para remover uma porcentagem que foi adicionada?

Não diretamente com estes três modos, porque você estaria dividindo em vez de subtraindo. Para remover um imposto incluído há um modo reverso dedicado na [calculadora de imposto sobre vendas](/en/finance/sales-tax-calculator), que faz essa aritmética corretamente.

## Como é arredondado?

Não é forçado a um número fixo de casas decimais — você vê o valor calculado. Arredonde-o você mesmo para qualquer precisão que seu contexto exija; arredondar cedo é uma fonte comum de erro quando porcentagens são encadeadas.

## Algo é enviado para um servidor?

Não. A aritmética funciona no seu navegador.
