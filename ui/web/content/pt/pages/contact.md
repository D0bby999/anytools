## E-mail

Para qualquer assunto, seja pedido de recurso, relato de bug, parceria, imprensa ou só para dizer oi, escreva para chaudai621@gmail.com. Procuramos responder em dois dias úteis.

## GitHub

O código e o rastreador de issues estão no GitHub. Abra uma issue para um bug, proponha uma mudança com um pull request ou leia o código: [github.com/D0bby999/anytools](https://github.com/D0bby999/anytools).

## Segurança

Achou uma vulnerabilidade? Relate em particular pelos avisos de segurança do GitHub: [Relatar uma vulnerabilidade](https://github.com/D0bby999/anytools/security/advisories/new). Por favor, não abra uma issue pública sobre ela. O SECURITY.md do repositório diz o que um bom relato deve conter e o que acontece depois.

## Imprensa e parcerias

Para imprensa ou propostas de parceria, escreva para chaudai621@gmail.com com "Press" ou "Partnership" no assunto.
