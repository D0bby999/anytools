## Correo

Para cualquier cosa, ya sean peticiones de funciones, informes de errores, colaboraciones, prensa o simplemente saludar, escribe a chaudai621@gmail.com. Intentamos responder en dos días laborables.

## GitHub

El código y el gestor de incidencias están en GitHub. Abre una incidencia si encuentras un error, propón un cambio con un pull request o lee el código: [github.com/D0bby999/anytools](https://github.com/D0bby999/anytools).

## Seguridad

¿Encontraste una vulnerabilidad? Infórmala en privado mediante los avisos de seguridad de GitHub: [Informar de una vulnerabilidad](https://github.com/D0bby999/anytools/security/advisories/new). Por favor, no abras una incidencia pública sobre ella. El SECURITY.md del repositorio explica qué debe incluir un buen informe y qué pasa después.

## Prensa y colaboraciones

Para consultas de prensa o propuestas de colaboración, escribe a chaudai621@gmail.com con "Press" o "Partnership" en el asunto.
