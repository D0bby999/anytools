## Email

For anything at all, whether feature requests, bug reports, partnership or press enquiries, or just to say hello, write to chaudai621@gmail.com. We aim to answer within two business days.

## GitHub

The code and the issue tracker are on GitHub. File an issue for a bug, propose a change with a pull request, or read the source: [github.com/D0bby999/anytools](https://github.com/D0bby999/anytools).

## Security

Found a vulnerability? Report it privately through GitHub's security advisories: [Report a vulnerability](https://github.com/D0bby999/anytools/security/advisories/new). Please do not open a public issue about it. The repository's SECURITY.md says what a useful report contains and what happens next.

## Press and partnerships

For press enquiries or partnership discussions, email chaudai621@gmail.com with "Press" or "Partnership" in the subject line.
