- `icon-192.png` (192×192, transparent background)
- `icon-512.png` (512×512, transparent background)
- `icon-maskable.png` (512×512, 80% safe zone for maskable)
- `apple-touch-icon.png` (180×180)
- `favicon.ico` (multi-size)

Generate from logo via https://realfavicongenerator.net or similar.
